# Code of Conduct

This project aims to be a welcoming place for everyone interested in better HTTP error responses in Java.

## The short version

- Be kind and assume good intent. Critique code and ideas, never people.
- No harassment, hate speech, trolling, or unwelcome advances — in issues, pull requests, discussions, or anywhere representing the project.
- Disagreements about design are normal and healthy; keep them technical and specific.

## Enforcement

Unacceptable behavior can be reported privately to othmane.ataallah.dev@gmail.com. Reports are handled confidentially, and maintainers may warn, temporarily limit participation, or permanently remove offenders depending on severity. Retaliation against reporters is itself unacceptable.

## Scope

These rules apply everywhere the project lives: the repository, its issue tracker, pull requests, discussions, and the documentation site.
