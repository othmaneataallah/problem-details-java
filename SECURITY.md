# Security Policy

This library deals with error responses, which sit close to information disclosure risks — reports are taken seriously.

## Reporting a vulnerability

**Do not open a public issue.** Email othmane.ataallah.dev@gmail.com with:

- What is affected (module, version) and what an attacker could achieve.
- Steps to reproduce, ideally as a small test or snippet.

You will get a response within a few days. Once a fix is agreed, it ships as a normal release and the reporter is credited unless they prefer otherwise.

## Supported versions

Only the latest release line receives security fixes. There are no long-term-support branches at this time.
